Datenschutzerklärung – TripKit

Stand: 7. September 2026

Entwickler: NorthPebble Apps / Sanel Basic
Kontakt: basicsanel87@gmail.com

1. Allgemeines

TripKit ist eine Offline-Beschäftigungs-App für Kinder im Alter von 4 bis 8 Jahren. Die App wurde insbesondere für die Nutzung unterwegs, zum Beispiel auf der Rückbank während einer Autofahrt, entwickelt.

2. Keine Benutzerkonten und keine Übertragung an Server

TripKit benötigt kein Benutzerkonto und verfügt über kein eigenes Backend oder einen eigenen Server. Nach der Installation laufen die Funktionen auf dem Gerät. Die App kann auch ohne Internetverbindung und im Flugmodus verwendet werden.

3. Lokal auf dem Gerät gespeicherte Daten

Falls innerhalb der App Einstellungen oder andere Informationen lokal auf dem Gerät gespeichert werden, verbleiben diese auf dem Gerät und werden von TripKit nicht an den Entwickler oder externe Server übertragen.

4. Werbung, Tracking und Analyse

TripKit enthält keine Werbung und keine Tracking- oder Analysefunktionen.

5. Inhalte und Funktionen

Die App enthält unter anderem Geschichten und Märchen, Zeichnen, Memory, Find-it und Puzzle-Funktionen. Die App enthält keine Funktion, mit der personenbezogene Daten an den Entwickler übertragen werden.

6. Kinder

TripKit richtet sich an Kinder im Alter von 4 bis 8 Jahren. Es werden über die App keine Benutzerkonten erstellt und keine personenbezogenen Daten an den Entwickler oder externe Server übermittelt.

7. Löschung

Da TripKit keine Benutzerkonten auf einem Server führt, gibt es keine serverseitigen Benutzerkonten zu löschen. Lokal gespeicherte App-Daten können über die Einstellungen des Android-Geräts gelöscht werden; alternativ kann die App deinstalliert werden.

8. Änderungen

Diese Datenschutzerklärung kann angepasst werden, wenn sich Funktionen der App oder die Verarbeitung von Daten ändern.
